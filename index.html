  1. Click Copy signature above.
  2. In Zoho Mail, open Settings ⚙ › Signature › Add new.
  3. Click in the editor and paste (Ctrl/⌘ + V). If the layout looks wrong, use the editor's Insert HTML option and paste the HTML code instead.
  4. Link it to your email address, set it as default for new mails and replies, then Save.
  1. Click Copy signature above.
  2. Classic Outlook: File › Options › Mail › Signatures. New Outlook: Settings › Accounts › Signatures.
  3. Click New, name it “Xite”, and paste.
  4. Under Choose default signature, pick your Zoho account for new messages and replies, then click OK.
  1. Click Copy signature above.

  3. Paste, then set it as the default for your Zoho account.
